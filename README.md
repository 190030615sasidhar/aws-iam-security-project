# AWS IAM Security Project

## Overview
This project focuses on securing AWS identity and access management using IAM users, groups, roles, policies, and MFA. The purpose of this project is to demonstrate cloud security best practices and the principle of least privilege.

## Objectives
- Configure IAM users and groups
- Apply least privilege access policies
- Enable MFA for user accounts
- Review access permissions
- Understand secure cloud identity management

## Tools & Technologies
- AWS IAM
- AWS Management Console
- MFA
- IAM Policies
- Cloud Security
- Access Control

## Key Security Concepts
- Identity and Access Management
- Least Privilege
- Multi-Factor Authentication
- Role-Based Access Control
- Cloud Security Best Practices
- Access Review

## Project Steps
1. Created IAM users and groups
2. Assigned permissions based on job responsibilities
3. Enabled MFA for additional account protection
4. Reviewed IAM policies for excessive permissions
5. Documented security recommendations

## Project Files
- `iam-security-checklist.md` - Checklist for IAM security best practices
- `sample-iam-policy.json` - Sample IAM policy demonstrating read-only access

## What I Learned
This project helped me understand how organizations manage secure access in cloud environments. I learned how IAM policies, MFA, and least privilege principles help reduce security risks and protect cloud resources.
